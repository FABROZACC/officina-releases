# officina-releases
Download e aggiornamenti di Officina
## Officina 1.0

Officina converte e modifica documenti, PDF, immagini e audio, tutto sul tuo computer: nessun file viene caricato su internet e non servono altri programmi installati.

### Cosa fa
- **PDF**: unisci, dividi, comprimi, organizza e ruota le pagine, firma, modifica il testo, proteggi con password, estrai le immagini, trasforma in immagini.
- **PDF → Word, PowerPoint, Excel**: con tabelle, colori e impaginazione; riconoscimento del testo (OCR) per le scansioni.
- **Word, Excel, PowerPoint → PDF**: con anteprima prima di salvare, più file insieme, fogli Excel a scelta.
- **Immagini**: converti, ridimensiona, ritaglia, comprimi, filigrana, rimuovi lo sfondo, ingrandisci con l'intelligenza artificiale, vettorizza in SVG, pixel art, mappe texture, icone, GIF.
- **Stampa**: dividi un'immagine in un poster su più fogli (con sormonto per incollare) o ripetila su un foglio.
- **Audio** e **libri EPUB**.
- **Rinomina in serie**, anche ridimensionando le immagini.

### Installazione
- **Mac** (Apple Silicon): scarica il file `.dmg`, aprilo e trascina Officina in Applicazioni.
- **Windows** (64 bit): scarica il file `.exe` e avvialo.

Gli aggiornamenti arrivano da soli: all'avvio Officina controlla se c'è una versione nuova.

Officina è gratuita (freeware). Contiene componenti liberi di altri autori: l'elenco è in Officina › Informazioni › Mostra tutte le licenze.
